# §11.1.6 Archive Trigger 실패

> umbrella doc §11.1.6 — §3.9 lifecycle 의 superseded 자동 archive 실패 (raw 변경 시)

- **Severity**: warning (반복 시 critical)
- **Detection**:
  - `x_devhub_status: superseded` 로 변경 안 된 previous concept 발견
  - audit log + sqlite `concept_index.status` 비교
  - §11.3 metric 5 (archive trigger failures) > 0/day (warning) / > 5/day (critical)
- **Triage**:
  1. source plugin 의 sync 결과 + normalized concept 비교
  2. `x_devhub_version` 비교 (이전 version 이 active 상태로 남았는지)
  3. bundle/index.md 의 archive 표시 정합
- **Mitigation**:
  - 운영자 수동 archive
    ```bash
    curl -X POST -H "X-DevHub-User-Context: ..." \
      -H "Content-Type: application/json" \
      -d '{"reason": "superseded", "note": "manual override"}' \
      http://localhost:8000/api/v0-2/concepts/{id}/archive
    ```
  - bundle/index.md 재생성
    ```bash
    curl -X POST http://localhost:8000/api/v0-2/bundles/{bundle}/rebuild
    ```
- **Recovery**:
  - archive 정상 적용 후 audit log success (`audit.concept.archive`)
  - viz.html 에서 superseded concept 가 archived 표시
- **MTTR target**: 1시간
- **Related**: §3.9.4 (archive 거부 정책), §3.6.6.1 (`audit.concept.archive` event)
- **M-v0.2.0 PoC note**: archive endpoint는 audit event만 emit (status field 변경 ❌). M-v0.2.3+ production 시 status field + viz.html 갱신.
