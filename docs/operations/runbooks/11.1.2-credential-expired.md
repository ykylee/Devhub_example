# §11.1.2 Credential 만료

> umbrella doc §11.1.2 — source plugin health check 의 401/403 응답

- **Severity**: warning (1시간 미복구 시 critical)
- **Detection**:
  - `audit.raw.received.last_error` = "401 Unauthorized" 또는 "403 Forbidden"
  - `GET /api/v0-2/ingest/{source}/status` 응답 `healthy: false`
  - source plugin `health_check()` 실패
- **Triage**:
  1. 외부 시스템의 credential 유효성 확인
     - Gitea access token
     - homelab agent token
     - Prometheus scrape credential
     - hrdb DB password
  2. credential 만료 / 회수 여부 확인 (운영자 또는 외부 시스템 admin)
- **Mitigation**:
  - **M-v0.2.0 PoC**: credential rotation 절차 (운영자 수동)
    - 외부 시스템 admin 의 새 credential 발급
    - backend-knowledge 의 source plugin 의 credential config 업데이트
  - **M-v0.2.1+**: credential 자동 rotation (외부 시스템 API 지원 시)
- **Recovery**:
  - 새 credential 로 sync 성공 시 audit log success
  - 1시간 이내 미복구 시 escalation (§11.4 on-call)
- **MTTR target**: 30분 (warning) / 1시간 (critical)
- **Related**: §11.1.1, §3.6.6.1 (`audit.config.change` event)
