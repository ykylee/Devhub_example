# §11.1.1 Source Plugin Sync 실패

> umbrella doc §11.1.1 — `POST /api/v0-2/ingest/{source}/sync` 호출 시 HTTP 4xx/5xx 또는 network timeout

- **Severity**: warning (5회 연속 실패 시 critical)
- **Detection**:
  - source plugin `health_check()` method 의 `last_error` 필드
  - `audit.raw.received` log 의 `last_error`
  - `GET /api/v0-2/ingest/{source}/status` 응답
  - §11.3 metric 1 (sync success rate) < 99% (warning) / < 95% (critical)
- **Triage**:
  1. `last_error` 메시지 확인 (401 → §11.1.2 / 429 → rate limit / 5xx → 외부 시스템 장애)
  2. 외부 시스템 status page 확인 (Gitea / homelab / metrics / hrdb)
  3. network connectivity 확인 (`curl`, `ping`)
- **Mitigation**:
  - 401/403 → §11.1.2 credential rotation
  - 429 → source plugin 의 retry policy 확인 + degraded flag 활용
  - 5xx → external system incident → 일시 정지 + 다음 cron cycle 대기
- **Recovery**:
  - sync 성공 시 audit log success
  - 5회 연속 실패 시 critical alert + on-call page
- **MTTR target**: 15분 (warning) / 30분 (critical)
- **Related**: §11.1.2, §11.1.3, §3.7.6.1 (partial failure detection)
