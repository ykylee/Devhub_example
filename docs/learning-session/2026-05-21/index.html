1. 프로젝트 개요 — Value Proposition

DevHub Example = 역할별 진입 페이지 우선순위로 UX 를 간접 제공하는 통합 개발 허브. 개발자/관리자/시스템 관리자가 동일 시스템에서 자기 역할에 최적화된 대시보드로 진입.

역할별 정보 탐색 최소화

Developer / Manager / System Admin 의 기본 진입 페이지 분리. 같은 권한 모델 위에 UX 분기.

단일 진실 source (SoT)

users 단일 테이블 + Keycloak OIDC 단일 IdP. 자체 accounts 테이블 없음.

외부 시스템 통합 single pane

DREQ (외부 의뢰) + External Integration (HomeLab/SCM/CI-CD) 통합 surface.

자동화된 추적성

REQ → UC → ARCH → API → IMPL → UT → TC 7단계 매트릭스. PR 마다 ID 발급 강제.

3. 시스템 아키텍처 — 단일 포트 + 5 도메인

핵심: 단일 포트 (ADR-0018) + Keycloak 단일 IdP (ADR-0019) + No-Docker 로컬 (ADR-0003)

4. 운영 정책 핵심 — 5건

1. No-Docker 정책 (default)

로컬 개발은 native (Go/Python/Node 직접 실행). Docker 자산은 환경별로 git 추적 외부. ADR-0003.

2. 단일 포트 진입

외부 진입은 https://<host>/devhub 만. nginx 가 backend / Keycloak 분기. ADR-0018 + PR #277.

3. 자동 마이그레이션

db-migrate 컨테이너가 backend boot 전 적용 + 30 retry × 2s healthcheck.

4. 추적성 자동 동기화

모든 PR 이 traceability/report.md §3 매트릭스 + 단계별 인덱스 갱신. ID 영구 (immutable).

5. self-review SOP (본인 PR 도 4단계)

diff 재검토 → gh pr comment → 보강 commit → squash merge. codex review cycle 과 병행.
