**cell 적용 (28 PoC cell)**: Performance NFR 은 32 cell 전체에 cross-cutting 적용 (모든 endpoint 응답 시간 정합). primary metric = NFR-P-001 (sync) / NFR-P-002 (query) / NFR-P-006 (reindex) 3 종.

### 2.3 NFR-3 Availability (가용성)

**목적**: backend-knowledge 의 incident 대응 (6 type) + backup-restore (5 target) + RTO/RPO 정공법. M-v0.2.0 PoC = daily backup + manual restore + 30분 RTO per incident. M-v0.2.3+ = PostgreSQL transactional backup + transactional 정합성 + 5분 RTO (PoC target).

**6 NFR** (umbrella doc §11.1 + §11.2 정합):
- **NFR-A-001**: Source plugin sync 실패 RTO < 30분 (§11.1.1)
- **NFR-A-002**: Credential 만료 RTO < 1시간 (§11.1.2)
- **NFR-A-003**: Pi ingest pipeline timeout/degraded RTO < 30분 (§11.1.3)
- **NFR-A-004**: Retention cron 실패 RTO < 4시간 (§11.1.4)
- **NFR-A-005**: Integrity violation RTO < 15분 (§11.1.5)
- **NFR-A-006**: Archive trigger 실패 RTO < 1시간 (§11.1.6) + Stale link 처리 MTTR < 30분 (M-v0.2.0 PoC, §11.1.7) / < 15분 (M-v0.2.1+ CLI) / < 5분 (M-v0.2.3+ auto-fix)

**Overall RTO/RPO** (umbrella doc §11.2 정합):
- **RTO** (Recovery Time Objective): < 5분 (M-v0.2.0 PoC) / < 15분 (M-v0.2.3+ production)
  - DB-sqlite: < 5분 (file copy + verify)
  - DB-PostgreSQL: < 30분 (pg_dump + psql)
  - bundles (git): < 5분 (git checkout)
  - raw (file mode tar): < 15분 (untar + verify sha256)
  - KEK / .env: < 1시간 (별도 secure storage retrieve)
- **RPO** (Recovery Point Objective): < 1시간 (daily backup + 매 cutover 직전 + 매 ingest 직후 snapshot)
  - 일별 backup: 7일 보관 (rolling)
  - 주별 backup: 4주 보관
  - 월별 backup: 12개월 보관
  - KEK / .env: 별도 secure storage 의 backup 정책 따름

**Backup 대상 (5 type, per storage mode)**:
- DB (raw_records): sqlite (M-v0.2.0~v0.2.2) / PostgreSQL pg_dump (M-v0.2.3+)
- var/bundles/: git push 가능 (Markdown + frontmatter)
- var/raw/ (file mode): 봉투 암호화 후 git push OR tar + S3 upload
- .env / KEK: 별도 secure storage (1Password / HashiCorp Vault)
- bundle_owner_org_id / governance field: git push (var/bundles/ 안)

**Restore drill** (per quarter):
- 월 1회 dry-run restore (운영 staging 환경)
- 분기 1회 실 restore drill (production 환경 test data)

**cell 적용 (28 PoC cell)**: Availability NFR 은 system-wide (5 backup target × 6 incident type = 30 cross-cutting cell). primary NFR = NFR-A-001 (sync 실패) + NFR-A-005 (integrity violation) + NFR-A-006 (stale link) 3 종.

**Path Y**: 6 NFR 모두 권장 (system incident 대응, audit attribution).

### 2.4 NFR-4 Observability (관측)

**목적**: 28 metrics M-v0.2.3+ production (umbrella doc §17.5) + audit log 7 event (umbrella doc §3.6.6.1) + 3-tier alert routing (info / warning / critical) + monitoring 도구 (FastAPI middleware + structlog → Prometheus → Grafana). M-v0.2.0 PoC = FastAPI middleware + structlog + 5 monitoring 지표. M-v0.2.1+ = Prometheus + Grafana. M-v0.2.3+ = 28 metrics full + governance dashboard 13 metric.

**6 NFR** (umbrella doc §11.3 + §17.5 + §3.6.6 정합):
- **NFR-O-001**: 5 sync/api baseline metrics (§11.3) — sync 성공률, query p95, integrity violation rate, Pi ingest success rate, archive trigger 정상 작동
- **NFR-O-002**: 5 Pi LLM metrics (§3.5.7.5) — MTTR / accuracy / false positive rate / SDK timeout rate / recommendation count
- **NFR-O-003**: 1 rollback metric (§3.5.8.3) — pi_link_resolve_rollback_count
- **NFR-O-004**: 4 API versioning metrics (§16.4) — v0-2/v0-3 request count / error rate / client identification / migration progress
- **NFR-O-005**: 13 governance dashboard metrics (§3.6.6.3) — audit log volume per user/org/project + RBAC denied + brute force + event type volume
- **NFR-O-006**: 3-tier alert routing (info / warning / critical) — Slack channel + on-call page (PagerDuty / Opsgenie) + escalation (30분 team lead / 1시간 director)

**Audit log 7 event** (umbrella doc §3.6.6.1 정합):
1. **user login**: 인증 event (Path Y caller-provided user context 의 hash + request_id 기록)
2. **concept access**: concept 조회 event (caller user_id + concept_id + visibility)
3. **curation edit**: concept 수정 event (caller user_id + curator_type + 변경 field)
4. **query**: 자연어 query event (caller user_id + query text + retrieval result count)
5. **archive**: concept archive event (caller user_id + concept_id + reason)
6. **publish**: concept publish event (caller user_id + concept_id + version)
7. **config change**: system config 변경 event (operator + 변경 field + before/after)

**Audit log format**:
- JSON Lines (1 event = 1 line)
- Daily file rotation (`audit-YYYY-MM-DD.jsonl`)
- 7일 retention default
- 90일 retention for security event (auth failure, RBAC denied, brute force)
- cross-trace 가능 (Path Y request_id + envelope trace_id 동일값)

**Monitoring 도구 진화**:
- M-v0.2.0 PoC: FastAPI middleware + structlog (JSON log) + 5 monitoring 지표
- M-v0.2.1+: Prometheus exporter (`/metrics` endpoint) + Grafana dashboard (5 지표 panel)
- M-v0.2.3+: 28 metrics full + governance dashboard 13 metric + audit log viewer 4 endpoint
- M-v0.3.0+: 외부 Datadog / Sentry 옵션 (M-v0.3.0+ 평가)

**cell 적용 (28 PoC cell)**: Observability NFR 은 system-wide (28 metrics × 32 cell = 896 cell × metric 매트릭스, 본 §4 cell × NFR 매트릭스에서 28 cell × 4 NFR = 112 조합). primary NFR = NFR-O-001 (5 sync/api) + NFR-O-005 (13 governance) + NFR-O-006 (alert routing) 3 종.

**Path Y**: 6 NFR 모두 권장 (observability 의 audit attribution 으로 필수). NFR-O-006 (3-tier alert routing) 는 **필수** (critical alert 15분 RTO + on-call page).

```python
# §2 FR FR-I-003 (POST /api/v0-2/raw) 의 봉투 암호화
# ADR-0025 정합 — AES-256-GCM
class EnvelopeEncryption:
    """
    봉투 암호화 (envelope encryption):
    - DEK (Data Encryption Key) per raw
    - KEK (Key Encryption Key) 1Password / HashiCorp Vault
    - AES-256-GCM algorithm
    - nonce 96 bit (random per encryption)
    - auth tag 128 bit
    """

    def encrypt(self, plaintext: bytes, kek: bytes) -> Envelope:
        """DEK 생성 + DEK 로 plaintext 암호화 + KEK 로 DEK 암호화."""
        dek = os.urandom(32)  # 256 bit
        nonce = os.urandom(12)  # 96 bit
        cipher = AES.new(dek, AES.MODE_GCM, nonce=nonce)
        ciphertext, auth_tag = cipher.encrypt_and_digest(plaintext)
        # KEK 로 DEK 암호화 (envelope)
        kek_cipher = AES.new(kek, AES.MODE_GCM, nonce=os.urandom(12))
        dek_encrypted, dek_auth_tag = kek_cipher.encrypt_and_digest(dek)
        return Envelope(
            ciphertext=ciphertext,
            nonce=nonce,
            auth_tag=auth_tag,
            dek_encrypted=dek_encrypted,
            dek_nonce=kek_cipher.nonce,
            dek_auth_tag=dek_auth_tag,
            algorithm="AES-256-GCM",
        )

    def decrypt(self, envelope: Envelope, kek: bytes) -> bytes:
        """KEK 로 DEK 복호화 + DEK 로 ciphertext 복호화."""
        # KEK 로 DEK 복호화
        kek_cipher = AES.new(kek, AES.MODE_GCM, nonce=envelope.dek_nonce)
        dek = kek_cipher.decrypt_and_verify(envelope.dek_encrypted, envelope.dek_auth_tag)
        # DEK 로 ciphertext 복호화
        cipher = AES.new(dek, AES.MODE_GCM, nonce=envelope.nonce)
        plaintext = cipher.decrypt_and_verify(envelope.ciphertext, envelope.auth_tag)
        return plaintext
```

**AC**:
- AC1: 모든 raw / bundle / concept 의 file mode 저장 시 봉투 암호화 적용 (AES-256-GCM, ADR-0025)
- AC2: DEK per raw (다른 raw 와 DEK 공유 ❌)
- AC3: KEK 1Password / HashiCorp Vault 별도 secure storage 보관
- AC4: decrypt 실패 시 500 `E_ENCRYPTION_FAILED` + audit log event

```python
# §11.3 + §17.5 정공법 — 3-tier alert routing
# info / warning / critical

class AlertRouter:
    """3-tier alert routing (info / warning / critical, §11.3 + §3.5.8.3 + §16.4)."""

    def route(self, alert: Alert):
        """
        Severity:
        - info: Slack #backend-knowledge-info (M-v0.2.1+), 1 business day
        - warning: Slack #backend-knowledge-alerts, 1시간, on-call responder
        - critical: Slack #backend-knowledge-critical + on-call page (PagerDuty / Opsgenie), 15분
          → 30분 미대응 시 team lead
          → 1시간 미대응 시 director
        """
        if alert.severity == "info":
            self._send_slack(channel="#backend-knowledge-info", alert=alert)
        elif alert.severity == "warning":
            self._send_slack(channel="#backend-knowledge-alerts", alert=alert)
            self._page_oncall(alert=alert)
        elif alert.severity == "critical":
            self._send_slack(channel="#backend-knowledge-critical", alert=alert)
            self._page_oncall(alert=alert)
            self._escalate_chain(alert=alert)
```

```
[SEVERITY] backend-knowledge incident

Detection time: {timestamp}

```
