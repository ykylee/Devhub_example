## 0. 사용 가이드

본 문서는 SDLC 요구사항 단계의 §1 = **도메인 분류**. 후속 단계:

1. **§1 도메인 분류** (본 문서) — source × type 매트릭스 + representative concept + REQ-ID
2. **§2 기능 요구사항 (FR)** — 4가지 기능 (Ingest / Curate / Query / Graph) × cell 매핑
3. **§3 비기능 요구사항 (NFR)** — 성능 / 보안 / 가용성 / 정합성
4. **§4 유스케이스** — actor × 시나리오
5. **§5 추적성 매트릭스** — REQ → IMPL → UT → TC

본 turn 작성 = §1 (도메인 분류). §2~§5 는 후속 turn.
