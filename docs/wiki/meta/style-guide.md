# Style Guide

- 문서 목적: 공개 위키 문서의 작성 톤과 품질 기준을 정의한다.
- 범위: 글쓰기 원칙, 금지 항목, 발행 전 체크 기준.
- 대상 독자: 문서 작성자, 리뷰어.
- 상태: accepted
- 최종 수정일: 2026-05-20

## 글쓰기 원칙

- 문제 → 선택 → 결과 순서로 작성
- 독립 문서로 읽히도록 배경 맥락 포함
- 기술 용어는 최소화하고 필요한 경우 짧게 정의

## 금지

- 내부 운영 경로/사설 인프라 정보 공개
- 미확정 계획을 확정 표현으로 게시
- 내부 backlog/handoff 내용 직접 공개

## 발행 전 체크

- 공개 범위(A/B/C) 확인
- 권한/보안 설명 최신 상태 확인
- 링크 유효성 확인
